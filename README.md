# 公寓管家 Windows 版（gongyuguanjia-win）

二房东/房产中介工作平台桌面端。数据与 iOS「公寓管家」通过腾讯云 COS + 云函数双向同步互通（一房一账本协议）。

- 技术栈：Avalonia 12 + C#（net10.0）+ SQLite + ClosedXML
- 版本：v1.0.0（对齐 iOS v1.82 功能与云端协议）

## 功能板块

工作台（KPI/未收租/包租付租/待办提醒）、房源（增删改/媒体/批量导入/微信H5分享/回收站）、成交（16字段/杂项收支）、收租（水电结算/退租登记）、包租、汇总（年/月切换）、待办（未办/已办）、设置（云端配置/口令鉴权/分享默认值/水印/压缩/备份恢复/回收站按板块清空/配色与自定义背景/日志/远程配置）。

## 云端协议要点（与 iOS 一致）

- 账本：一房一文件 `h/<房号>/info.json`（CloudHouseRecord 同构，最后写入优先）
- 签名：COS 预签名 URL（未编码路径参与签名、保留斜杠、q-header-list 含 content-type）
- 列表：ListObjectsV2 翻页 + encoding-type=url + CommonPrefixes
- 删除：云端已删（both/cloud）本地跟随删，不复活；local 聚合补传
- 媒体：三名单对账（账本/本地记录/磁盘），下载失败绝不删云端；孤儿只删文件
- 视频：统一转 mp4 + 用户区首帧图
- 备份：`users/<用户名>/backups/`，云端保留 10 份，恢复前自动安全备份+失败回滚
- 分享：H5 双版（客户脱敏/同事完整）、水印、二维码、名片、链接有效期、访问统计
- 云函数：k=SHA256(管理后台口令) 鉴权（configGet/logOp）
